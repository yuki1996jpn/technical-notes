# macOS ターミナル（Zsh）操作メモ

### シェルスクリプト作成

1. `~/bin` に移動してスクリプトファイルを作成する

```
cd ~/bin
```

2. 先頭にシバン（`#!/bin/zsh`）を記述してからスクリプトを書く

```
#!/bin/zsh
```

3. 実行権限を付与する

```
chmod +x ~/bin/スクリプト名
```

---

### サブシェルと `source` の違い

通常、シェルスクリプトを実行すると**現在のシェルとは別のプロセス（サブシェル）**で動作する。

1. スクリプトを実行すると子プロセス（サブシェル）が作成される
2. スクリプト内の `cd /path/to/dir` などで子プロセスのカレントディレクトリが変わる
3. スクリプト終了と同時に子プロセスも終了する
4. 親プロセス（元のZsh）のカレントディレクトリは変わらない

スクリプト内の `cd` などの環境変更を**現在のシェルに反映させたい場合**は、`source` または `.`（ドット＋スペース）で実行する。

```
source スクリプト名
# または
. スクリプト名
```

### ファイル名を再帰的に検索する

```
ls /path/to/target/directory/**/*word*.txt
```

### ファイルの中身を再帰的に検索する

```
grep "word" /path/to/target/directory/**/*.txt

# カレントディレクトリ以下を対象にする場合
grep "word" **/*.txt
```

- `**`：カレントディレクトリ以下の全サブディレクトリを再帰的に検索
- `*`：任意の文字列を表すワイルドカード

### シンボリックリンク

新規作成する。
```
ln -s <リンク対象のパス> <作成するパス>
```

リンク先を変更する。
```
ln -sfn /新しいリンク先のパス /変更したいシンボリックリンクのパス
```
-s: シンボリックリンクを作成する。
-f: 既存のリンクを上書きする。
-n: リンク先がディレクトリだった場合に、その中へリンクを作らず、リンク自体を置き換えます（最重要）。

シンボリックリンクの**実体**を基準に一つ上のディレクトリへ移動するには `-P`（Physical）オプションを使う。

```
cd -P ..
```

---


### カレントディレクトリのフルパス取得・コピー

```
# シンボリックリンクを解決した実体のフルパスを表示
pwd -P

# クリップボードにコピー
pwd -P | pbcopy
```

---


### ファイル・ディレクトリのデータ量確認

- `-l`：詳細表示（Long format）
- `-h`：人間が読みやすい単位で表示（Human-readable）

```
# ファイルサイズ
ls -lh ファイル名

# カレントディレクトリの合計サイズ
du -sh .
```
