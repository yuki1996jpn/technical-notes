# Vim：オペレーター × タグ操作（d/y/c × it/at）

Vimにおける `d`、`y`、`c` は**オペレーター**、`it`、`at` は**テキストオブジェクト**と呼ばれ、これらを組み合わせることでHTML/XMLタグの編集を効率的に行うことができる。

## オペレーター（操作）

- `d` (**d**elete)：削除する
- `y` (**y**ank)：コピー（ヤンク）する
- `c` (**c**hange)：変更する（削除してインサートモードへ移行）

## テキストオブジェクト（対象範囲）

- `it` (**i**nner **t**ag)：タグの**内側**のみを指す（開始タグと終了タグは含まない）
- `at` (**a** **t**ag)：タグ**全体**を指す（開始タグと終了タグを含む）

## 組み合わせコマンド一覧

| コマンド | 動作 | 対象範囲 |
| :--- | :--- | :--- |
| `dit` | 削除 | タグの内側 |
| `yit` | コピー | タグの内側 |
| `cit` | 変更 | タグの内側 |
| `dat` | 削除 | タグ全体（タグを含む） |
| `yat` | コピー | タグ全体（タグを含む） |
| `cat` | 変更 | タグ全体（タグを含む） |
